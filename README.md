# Novus CFC

Site de apresentação do Novus CFC, sistema de gestão para autoescolas. O produto é o foco único do site e toda a experiência fica na rota raiz (`/`). A rota `/novus-cfc` mantém o mesmo conteúdo como endereço alternativo.

## Stack

- Astro 5
- React para a navegação responsiva
- Tailwind CSS 4

## Desenvolvimento

```sh
npm install
npm run dev
```

## Build e pré-visualização

```sh
npm run build
npm run preview
```
